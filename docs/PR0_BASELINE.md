## TypeScript and testing

`tsconfig.json` is the configuration generated by this exact Next.js 16.2.6
installation via `next typegen`. Its default `strict: false` was retained;
application files were not edited to satisfy new rules. `next-env.d.ts` and
route types are generated before `tsc --noEmit` and are not committed.

| Added devDependency | Version | Purpose |
| --- | --- | --- |
| vitest | 4.1.11 | One test runner and module mocks |
| @testing-library/react | 16.3.3 | Render and interact with React components |
| @testing-library/dom | 10.4.1 | Required DOM query peer for React Testing Library |
| jsdom | 30.0.1 | Browser-like DOM without a real browser |

Eight smoke tests cover Home and adapted synthetic properties, numeric prices
and known types, cards, drawer/gallery opening and closing, a single operation
filter, empty filtered results, publication render/required fields, valid local
photo selection, catch-all resolution and the fetch guard. Some tests cover
multiple assertions. No E2E framework is needed for this limited scope.

Fixtures contain fictitious sale/USD and rent/PEN records, house/apartment/land,
embedded images, no-image records, and an empty inventory export. The existing
inline Home adapter is exercised through rendering, without extracting it.

Supabase module and SDK are mocked; reads use fixture copies, Realtime is inert,
and writes/Auth/Storage throw. The map is replaced at the dynamic import boundary.
Browser fetch, XMLHttpRequest and WebSocket throw if invoked. jsdom does not load
external image/stylesheet resources by default. These guards cover the tested
application paths, not arbitrary OS-level networking. Real keys are never needed.

See [KNOWN_ISSUES.md](../KNOWN_ISSUES.md). The tests are not a certification of
Leaflet, focus behavior, publication writes, currency formatting or remote-empty
inventory behavior. No functional defect was repaired or enshrined as correct.

## Reproduce and CI

Use Node 24.20.0 and its npm 11.19.0. Leave both public Supabase variables empty
and do not copy a production `.env` into this checkout.

```sh
npm ci
npm run typecheck
npm test
npm run build
```

For a clean build, remove only the local `.next` directory first. `npm ci`
replaces local node_modules using the committed lockfile. The workflow
`.github/workflows/pr0-baseline.yml` runs these checks for pull requests and
manual dispatch, on Ubuntu 24.04, with verified immutable action SHAs and a
runtime version check. It has read-only contents permission and no deployment
step, Railway command or Supabase credentials. Branch protection was not changed.
